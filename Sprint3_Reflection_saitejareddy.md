PERSONAL REFLECTION ON SPRINT 3 

During this sprint, my main concentration was on the implementation of the Favorite feature and creating the basic functionality for our Event Organizer application. My major contributions included the ability for a user to mark events as favorites and view them in a separate section for easy access. I also provided a foundation for the core functionality of event management: creating events, updating, and deleting, besides giving users a way to correctly input the name, date, and location details of events. In this instance, these features are central to the usability of an application, providing a solid base for further enhancements. One of the challenges was how to keep the data consistent throughout the application-in particular, when adding or removing events from the favorite list.

The other sensitive topic was debugging database queries and handling some edge cases, like duplicate entries or no data at all. To solve these challenges, I have tested the database operations thoroughly and integrated meaningful error messages that will guide users whenever their inputs were wrong or incomplete. Also, date validation required some tuning to get it to work as expected, but I did manage to provide a pretty reliable solution that checks for correct formatting. In this sprint, I learned a lot about database administration and UI design. I further honed my learning in structuring SQL queries in relational databases, which came in handy while gluing user interactions with stored data effectively. Secondly, I did some hands-on work on how to create user-friendly interfaces using ttkbootstrap, further improving the visual appeal of the app and its overall usability. These skills will be invaluable in future sprints as we extend the functionality of the app. One improvement area, in retrospect, could have been time management.

Though I was able to finish my tasks, I felt it later in the sprint that breaking down tasks into more minor, subtasks may have smoothed out the workflow.

Additionally, coordinating with the team better on how to integrate our features into one would have further improved our progress, as there were some minor conflicts in the merge process. Therefore, for the next sprint, I focus on improving communication within the team and refining existing features for seamless user experiences. Overall, this sprint was productive, and I look forward to continuing with the excellent foundation we laid down as we keep working on our application.
